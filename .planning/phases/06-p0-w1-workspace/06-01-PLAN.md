## Trust Boundaries

| Boundary | Description |
| --- | --- |
| Claude hook stdin → `pre_tool_guard.py` | 完全不可信 JSON/类型/命令文本进入安全决策边界。 |
| Bash 文本 → shell pattern classifier | 攻击者可用链式命令、路径前缀、大小写和相似安全命令尝试绕过或诱发误报。 |
| PostToolUse env/script path → filesystem | env 与脚本位置决定审计写入根，错误推导可能越界或写入不可写目录。 |
| Hook payload → audit record | tool input/response 可能包含凭据、endpoint 或敏感业务数据，只允许最小 metadata。 |
| Repository bootstrap source → runtime initialization | 仓库初始化源会进入空卷；cache、secret、symlink 或越界文件可污染运行态。 |
