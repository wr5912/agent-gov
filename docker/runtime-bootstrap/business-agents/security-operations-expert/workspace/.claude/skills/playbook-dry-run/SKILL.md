## 边界

只审核方案，不保存、不批准、不执行、不监控，也不生成可直接运行的操作内容。

## 流程

1. 核对方案来源、授权范围、证据依据和适用条件。
2. 核对调用方提供的已发布方案摘要与能力摘要是否完整且适用。
3. 评估影响、风险、回退考虑、验证标准和人工复核项。
4. 对缺失或无法核实的信息标记 `needs_human_review`。

## 输出

- 审查结论：可供平台评审 / 需调整 / 需人工复核。
- 风险、影响与证据缺口摘要。
- 阻断性问题及建议补充的验证条件。
