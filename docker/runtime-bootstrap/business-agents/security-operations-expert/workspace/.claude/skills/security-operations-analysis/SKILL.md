## 边界

- 仅处理明确授权范围内的防御性安全运营材料。
- 只读查询证据，不产生 SOC 或系统副作用，也不生成可直接运行的命令、脚本或操作链。
- 每个结论都区分事实、推断、置信度和证据缺口。
- 敏感信息只保留最小必要摘要。

## 流程

1. 确认授权边界、时间范围、对象标识、业务影响和期望产出。
2. 使用用户材料和平台传入的脱敏 typed context，并记录来源与缺口。
3. 归纳可引用事实，对推断标注依据和置信度。
4. 按证据强度、业务重要性、影响范围和紧迫度排序风险。
5. 输出补证据、监测、缓解和恢复建议；需要系统变更时只形成响应方案摘要。

## 输出

- 安全运营结论、风险等级和置信度。
- 证据与事实、推断与缺口。
- 防御建议、前置条件、影响范围和验证标准。
- 如需平台响应，说明进入 `threat-response-disposition` 的理由。
