## 安全约束

只做静态分析，不调用 SOC 写工具、不执行真实预检，也不把模型判断冒充动作目录校验结果。

## 步骤

1. 读取用户或 RO 提供的完整剧本及来源；不得从当前 MCP 猜测缺失的剧本或原子动作目录。
2. 只有 RO 同时提供已核实的动作定义、参数 Schema 和适用范围时，才基于这些事实做静态对照；否则标记 `needs_human_review`。
3. 评估已知影响范围、可能的连带影响、回滚可行性与需人工确认的步骤。

## 输出

- 静态评估结论：材料充分 / 需调整 / `needs_human_review`；不输出“已通过真实预检”或“可执行”
- 逐步风险标注与整体影响范围
- 阻断性问题清单（动作不存在、参数非法、缺回滚等）
